# model-kit-paint-planner

A planning tool for painting model kits (Gunpla and others): upload a photo of your kit, get
several color schemes built from **real paints** (Mr. Color, Tamiya, Gaia) with paint codes.

Planned design: everything runs in the browser and is hosted free on a static site. Nothing is
generated by an image AI: the kit photo is segmented and recolored region by region, so
proportions and details stay exactly as built.

**Status:** the paint database is built (`data/paints.json`). The web app (`web/`) can select
parts with a click, assign real paints and show the repaint live; automatic schemes come next.

## Running the app

```sh
cd web
npm install
npm run dev     # regenerates web/public/paints.json, then starts Vite
npm test
```

### Saving projects

- **Autosave:** the open project is kept in your browser (IndexedDB) and offered as
  "Continue where you left off?" on the next visit. It stays on your device.
- **Save project** (Ctrl/Cmd+S) downloads `<photo>.kpp.png`. It is an ordinary PNG of the
  repainted kit with a paint legend, so it previews anywhere. Drop it back into the app to keep
  working. The project travels inside the PNG in private chunks: `kpPj` (JSON: regions, paint
  choices, and a snapshot of each paint's color), `kpMp` (deflated Int16 region map) and `kpIm`
  (the original photo at working resolution). Typical size is 1–2 MB.
- If a paint's color data changed since the file was saved, or the paint was removed, the app
  says so when you open it.
- Sites that recompress uploads (Discord, Reddit, most social media) strip the project data.
  Share the file as an attachment or through a file host if others should be able to open it.
- The file contains your photo.

## Paint data

`data/paints.json` is generated from the manufacturers' own published swatches:

| Brand | Source | Color from | Names / finish from |
|---|---|---|---|
| Mr. Color (C1–C189) | mr-hobby.com | Official color lineup chart (chip median) | Official English color list PDF (G / SG / M / ME / PA) |
| Mr. Color lines: GX, GX Clear, GX Metal, Crystal, Super Metallic 2, Velvet, GGX, Gundam Color (UG), C511–530, Lascivus | mr-hobby.com | Per-line lineup charts: chips, or photographed painted samples (GX Metal spheres, GX Clear discs); swatches detected automatically | Transcribed from the charts in `data/sources/mrcolor_lines.csv` (finish printed on the chart); GX Metal/Clear names cross-checked with the color list PDF |
| Tamiya (LP, X/XF, TS) | tamiya.com | Product color chip (chip median) | Product title + description (finish inferred) |
| Gaia Color | gaianotes.com | Swatch hex on the official color chart page | English names from [Newtype](https://newtype.us) retail listings, cross-checked against the English printed on Gaia's bottle labels (`data/sources/gaia_labels.csv`); finish from the labels where printed |

Gaia's chart is Japanese-only. `data/sources/gaia_labels.csv` is a hand transcription of the
official bottle labels, plus English translations for Japanese-only labels (railroad series)
and romanized/German names. Corrections to that file are welcome.

> **These are screen approximations, not measurements of dried paint.** Manufacturers draw
> idealized swatches (e.g. Mr. Color C1 White is pure `#ffffff`). Use them for planning, and
> test-spray before committing.

### Record fields

| Field | Meaning |
|---|---|
| `id`, `brand`, `line`, `code`, `name`, `name_ja` | Identity (`name` is English; `name_ja` is the original Japanese for Gaia) |
| `name_sources` | Gaia and the Mr. Color lines: each candidate English name by source (`newtype.us`, `bottle label`, `translated`, `chart (translated)`) |
| `hex`, `lab` | sRGB hex and CIELAB (D65) |
| `finish` | `gloss`, `semi-gloss`, `flat`, `metallic`, `pearl`, `clear`, `clear-color` (tinted clear / candy), `fluorescent`, or absent if unknown |
| `finish_source` | `official` (printed by the maker), `retailer` (from a store listing), `inferred` (from name/series/description), `manual`, `unknown` |
| `is_color` | `false` for clear coats, flat bases and topcoats; scheme generation should skip these |
| `confidence` | `medium` by default; `low` when the source value looks wrong (see `notes`) |
| `sheen_lab_range` | For metallic/pearl chips drawn as gradients: darkest/brightest Lab, a rough sheen hint |
| `equivalents` | Same-maker equivalents (e.g. Tamiya LP-72 ↔ TS-76) |
| `samples` | Extra swatches, e.g. Mr. Crystal Color sampled `over white` and `over black` |
| `source_url`, `image_url`, `source_method` | Where the value came from |

### Rebuilding

Requires [uv](https://docs.astral.sh/uv/).

```sh
uv sync
uv run python -I -m kpp_scraper.build            # all brands
uv run python -I -m kpp_scraper.build gaia       # one brand
uv run python -I -m kpp_scraper.build --refresh  # ignore the download cache
```

Downloads are cached in `.cache/` (not committed) and requests are rate-limited to one per
second per site. Each run also writes QA contact sheets to `.cache/qa/<brand>.png`, showing the
source swatch next to the extracted color. Check these after any source change.

The scrapers identify themselves with a `model-kit-paint-planner` user agent and only use pages the
sites' `robots.txt` allows.

## Contributing corrections

If a paint looks wrong compared with the real thing, open an issue with the paint code and,
ideally, a photo of a sprayed sample next to a printed gray card or color reference.
